# Toyomimi — 分阶段计划

> 起点：fork 自 my-translator v0.9.1。本计划只写**我们要改什么**，上游已有的能力（系统声音采集、悬浮字幕、双栏、签名、自动更新）直接继承。

## 核心设计：对称部署

```
你（中文）                                 对方（英文 / 日文）
扬声器（对方说的英文）→ 中文字幕            扬声器（你说的中文）→ 英文 / 日文字幕
```

- 每个 App 只做一件事：**把扬声器声音翻成「我的语言」**，源语言自动识别
- 三方及以上会议无需额外设计：每人都把所有人的发言翻成自己的母语
- 默认不翻麦克风（不戴耳机时麦克风会录进对方声音 → 重复翻译）；麦克风通道作为可选
- 双方之间零协议 → 各自可用不同引擎、不同账号

## 阶段

| 阶段 | 内容 | 验收标准 |
|---|---|---|
| **0 · 验证** | ① 本机构建并试用上游 App 作为基线 ② 写 `scripts/phase0/` 测试程序：音频文件按真实语速推流，记录事件与时间戳 ③ Qwen3.8 vs Soniox 对比：延迟、质量、成本、60 分钟稳定性、多人 / 背景音乐 / 日语 / 中英夹杂 ④ 通读上游代码，评估可维护性 | 一份测试报告（`docs/toyomimi/phase0-report.md`）：实测数据 + 继续 / 调整的建议 |
| **1 · Mac 可用版** | 改身份（名称、identifier、updater、图标）· 升级 Qwen 接入到 3.8（说话人标签、热词）· 中国区 / 国际区配置（地域 + Key + 业务空间 ID）· 中文界面 · 「我的语言」为一等设置 | 用它和英语母语者开完一场 30 分钟的 Zoom / 腾讯会议，全程看得懂 |
| **2 · Windows + 完善** | Windows 构建与测试 · 麦克风通道 · 热词管理 · 会议记录导出 | 对方在 Windows 上也能用 |
| **3 · 扩展** | 日 / 法 / 西语调优 · 对方免安装（网页字幕 / 虚拟麦克风）· 更多引擎 | 按需 |

## 第 0 阶段测试维度

| 维度 | 方法 | 产出 |
|---|---|---|
| 延迟 | 对照原音频句子边界与译文返回时间 | 首字延迟、整句延迟（对照官方 2.3 秒） |
| 质量 | 公开中英片段 + 真实会议 / 视频片段，逐句评审，必要时 COMET | 准确度、术语一致性、典型错误 |
| 场景 | 多人对话、带 BGM 视频、日语、中英夹杂、原文即目标语言 | 能用 / 不能用的边界 |
| 成本 | 读服务端用量统计 | 每小时实际花费 |
| 稳定性 | 连续推流 60 分钟 | 会话时长上限、断线重连 |

## 前置条件（维护者准备）

- 阿里云百炼**北京地域** API Key + 业务空间 ID → 写进本仓 `.env`（不要贴进聊天）
- Soniox API Key（有免费额度）
- 2–3 段真实会议录音 / 常看视频片段 → 放 `local/test-audio/`
